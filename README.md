# anita-chandrasekharan.github.io

Source for my portfolio site, published at https://anita-chandrasekharan.github.io.

Plain HTML and CSS, no build step. GitHub Pages serves the `main` branch.

## Adding a project

1. Copy `projects/_template.html` to `projects/<project-name>.html` and fill in each section.
2. Put images in `assets/`.
3. Add a card for the project in `index.html` under `#projects`.
